New project

Post a project in four steps

You become the client. The budget is locked when you post, and the criteria you write are the only thing the AI may use to pick the winner.

What needs to be done?

Start from a template or write your own.

How will the winner be chosen?

Up to 6 criteria. Tap the bars to set the weight from 1 (nice to have) to 5 (critical). Each bid is scored 0 to 3 on each one. Mention price or speed here only if you want them to count.

How will the work be paid?

Up to 5 milestones, shares adding up to 100%. The acceptance text is what the arbiter checks if you dispute a delivery, so write it so a stranger could verify it from a web page.

Money and timing

Enter a budget to see the bond.

Every bidder locks the bond. Losers get it back at selection. The winner gets it back after the last milestone, and loses it if the work is never delivered. 1% to 30%.

How it works

Rules first. Then bids. Then money.

BidRoom is one GenLayer Intelligent Contract. The client writes the rules before anyone bids, and every later step is checked against them.

💰
PHASE 01

Bidding

The client locks the budget and writes weighted criteria and milestones. Freelancers lock a small bond and bid a price, a time and a proposal. Bids can be withdrawn until the window closes.

⚖
PHASE 02

Selection

Anyone triggers it. Every validator scores each bid 0 to 3 on each criterion without seeing who bid. Code adds up the weights, breaks ties by price, and requires at least 34% of the maximum.

📦
PHASE 03

Delivery

Milestone by milestone. The winner submits a link; the client approves, or stays silent for the review window, which counts as approval. A missed deadline lets anyone refund the client.

🔍
PHASE 04

Dispute

The client may contest a delivery in time. An AI arbiter reads the delivered page against the acceptance text and must quote it: accepted, partial (50/50), or rejected with one redo.

Who does what

Client

Creates the project, locks the budget, writes criteria and milestones, reviews each delivery.

Bidder

Any other wallet. Locks a bond and posts a price, a time and a proposal.

Winner

The selected bidder. Confirms the award, delivers one link per milestone, gets paid as work is approved.

Anyone

Triggers the steps nobody can block: selection, rulings, auto-approval, refunds.

Questions

Can the AI be talked into picking someone?

Proposals are passed as untrusted data, bidders are hidden behind labels, and a proposal that addresses the evaluator is scored 0. Every validator scores independently and must reach the same winner, so one model run cannot decide alone.

What if the AI cannot decide?

Nothing is recorded and anyone can try again. If selection is never completed, everyone is refunded 24 hours after bidding closes. An unresolved dispute splits the milestone 50/50 after 72 hours.

Which delivery links should I use?

Links that cannot change after delivery, for example a GitHub file at a specific commit. The arbiter reads the page when it rules.

Who holds the money?

The contract. Every payout is credited to a balance that only its owner can withdraw, so nobody can block anyone else's money.
